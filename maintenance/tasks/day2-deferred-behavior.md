# Day 2 주석에서 분리한 동작 변경 작업

2026-11-06: 이번 구조 정리는 API·DB 동작을 보존한다. 아래 7건은 구현 완료가 아니라 별도 작업으로 등록한 항목이다. 오래된 카테고리 추가 요청과 Mapper 도입 제안은 현재 구현에 필요하지 않아 제거했다.

| 작업 | 현재 동작·영향 | 재현 또는 측정 | 별도 작업 완료 기준 |
|---|---|---|---|
| FCM 일시 실패 복구 | 청크 전송 예외를 기록하고 다음 청크로 진행하며 재시도하지 않음 | 테스트 발송기에 일시 오류·영구 오류를 주입하고 청크별 시도/성공/중복 수 확인 | 일시/영구 오류 구분, 재시도 상한·지연·중복 전달 정책을 합의하고 실패 후 복구 회귀 통과. #435 실행기 측정과 영속 복구를 구분 |
| 지원자 학년 정렬 | enum 문자열 오름차순으로 FIRST→FOURTH→SECOND→THIRD가 될 수 있음 | 학년별 지원자 4명으로 GRADE 조회 순서 확인 | 별도 동작 수정으로 1→2→3→4학년과 같은 학년의 ID 순서, 페이지·검색·전형 조건 회귀 통과 |
| 부원 페이지 조회 비용 | 페이지 번호에 따른 offset 조회 | 같은 데이터·페이지 크기로 앞/뒤 페이지의 실행계획·지연 측정 | 병목을 확인한 경우 현재 페이지 번호 계약 유지안과 커서 API 변경안을 비교해 합의 후 구현·회귀. 병목이 없으면 측정 근거로 종료 |
| 부원 Excel 메모리 | XSSFWorkbook으로 전체 워크북을 메모리에 구성 | 실제 최대 부원 규모와 큰 입력에서 peak heap·시간·출력 내용 비교 | 메모리 문제가 확인된 경우 SXSSFWorkbook 전환 및 임시파일 정리·예외 시 자원해제·다운로드 내용 회귀. 문제가 없으면 측정 근거로 종료 |
| CORS 허용 헤더 | allowedHeaders("*") 사용 | 실제 프론트 preflight 헤더와 인증/파일업로드 요청 조사 | 허용 목록 축소 필요성 합의 후 정상 origin·헤더와 비허용 요청을 검증. 조사 전 현재 정책 유지 |
| 지원폼 생성 검증 | 요청의 기존 필수값 검증을 사용 | 역전 날짜·0/음수 인원·빈 학년/질문 요청과 기존 도메인 검증 결과 확인 | 허용할 임시/정식 입력 정책과 기존 클라이언트 영향을 합의한 뒤 일관된 400 응답·저장 미발생 테스트 통과 |
| 답변 질문 ID 저장 | Answer JSON은 제목·질문 유형 등으로 저장하며 질문 ID 없음 | 제목 변경·동일 제목 질문에서 기존 답변 연결의 모호성 확인 | ID 추가 필요성을 확인한 뒤 기존 JSON/API·데이터 호환성과 전환 절차 합의, 과거·신규 답변 조회/제출 회귀 통과 |

운영 실험·공개 이슈 생성·API/데이터 변경은 이 문서 등록에 포함되지 않는다.
